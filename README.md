# StudyTime - Grupo P

## Programación de Dispositivos Móviles

### Proyecto: StudyTime

StudyTime es una aplicación móvil orientada a ayudar a estudiantes a gestionar el tiempo dedicado al estudio, lectura, preparación para exámenes, asignaciones y ocio.

Esta práctica corresponde a la Unidad IV y tiene como objetivo implementar un módulo de conectividad utilizando Ionic, Angular y Capacitor.

## Entregables

### Entregable 1 - Detector de Red

Implementación del plugin @capacitor/network para detectar el estado Online/Offline de la aplicación en tiempo real.

### Entregable 2 - Modo Offline

Implementación de almacenamiento local para permitir que StudyTime continúe funcionando sin conexión a Internet.

### Entregable 3 - Documentación Técnica

Documentación del funcionamiento del módulo, arquitectura, pruebas, capturas y diagrama de flujo.
