# Audio local

`tono-suave.wav` es un tono sintético de 20 segundos generado para StudyTime con asistencia de IA: seno de 220 Hz y armónico de 330 Hz, volumen reducido y entrada/salida gradual. No usa grabaciones de terceros. Se ofrece con licencia CC0. No se afirma que tenga efectos terapéuticos o mejore el aprendizaje.
